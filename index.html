권역별 청약·미분양·공급·가격 지표를 분양 사업성 관점의 신호등으로 표시합니다.

기간

신호등은 분양 사업성 관점입니다. 파랑은 양호, 주황은 보통·관망, 빨강은 주의입니다. 회색은 해당 기간 자료가 없는 곳입니다.
API 표시는 공공 API에서 자동 수집한 값, 조사값 표시는 API 연결 전 공표 자료를 조사해 넣은 값입니다.
